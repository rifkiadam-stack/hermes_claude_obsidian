# Islamic lectures — conditional guidance

Read only with `transcript-sources.md` for an Islamic lecture processed under
`ingest transkrip`. This short reference preserves attribution; it does not
introduce another workflow, review round or external fact-checking requirement.

- Distinguish the speaker's explanation, quoted Quran/hadith, stories, analogies,
  differing views and agent reflection. Preserve context and qualifications.
- Do not turn advice into a universal ruling, personal explanation into consensus,
  or a summary into a fatwa. Attribute statements to the speaker where appropriate.
- Never guess or complete Arabic text, transliteration, narrator names, verse
  numbers, hadith sources/grades or legal schools from model memory or unclear
  captions. Keep supplied clear text as source quotations, not authenticated evidence.
- For an unclear reference, preserve the understandable idea with attribution and
  label the reference unverified. If ambiguity prevents a faithful central meaning,
  do not derive a religious conclusion; skip the source and report the limitation.
- Do not invent theological discussions or differences between schools absent from
  the source. Matching captions does not authenticate scripture, translation or hadith.
- The same single pre-apply transcript reviewer checks fidelity and attribution;
  do not add a second religious-review pipeline. External authentication is a separate
  task requiring explicit scope and sources, never a silent correction to raw.
- Use the existing vault destination and active MOC. Do not create a lecture-specific
  folder/category/MOC. Resolve a destination from established user/vault conventions;
  if genuinely ambiguous, skip and report rather than modifying vault configuration.
